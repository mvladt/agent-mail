# Упаковка agent-mail

- Скрипт Pi выделен в самостоятельный проект; интерфейс пяти команд сохранён.
- Добавлены проверки аргументов, уникальные временные файлы и публикация без перезаписи.
- README описывает установку, обновление, подключение агентов и ограничения.
- Тест проверяет доставку, подтверждение, ответ, ожидание и параллельную отправку; на macOS пройден.
- Тесты GitHub Actions пройдены на Linux и macOS; репозиторий опубликован: https://github.com/mvladt/agent-mail.
- После ревью уточнены права `600` и работа под одним пользователем ОС; локальная команда переключена на репозиторий. Лицензия отложена по решению владельца.
